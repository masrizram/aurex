# AUREX Design Partner Alpha — Phase 9

## Objective

```
Acquire the first real design partner
and produce one externally verifiable
economic outcome within 30 days.
```

## Success Criteria

```
≥ 1 real business (with real transactions)
≥ 1 real objective (measurable economic target)
≥ 3 completed AEE cycles
≥ 1 verified economic improvement (Δ vs baseline)
≥ 1 payment attempt (willingness-to-pay test)
```

## Failure Condition

```
No measurable customer value created
→ PIVOT or REDesign
```

## Decision Gate

```
After 30 days:

SCALE    → if verified value + payment received
ITERATE  → if value created but no payment yet
PIVOT    → if no measurable value
```

---

## Partner Criteria

### Ideal Partner 1

```
✅ Real business with real transactions (not hobby/side project)
✅ Revenue or cost that can be measured (not vanity metrics)
✅ Owner/decision maker accessible directly
✅ Willing to share business data (revenue, cost, customers)
✅ Problem solvable in 2-4 weeks (not enterprise 6-month cycle)
✅ Current revenue: Rp50jt-Rp500jt/month (SME sweet spot)
```

### Avoid

```
❌ Enterprise with 3-month approval chains
❌ Pre-revenue startups (no baseline to measure against)
❌ Businesses without measurable economics
❌ "I want to try AI" curiosity seekers (not committed to outcome)
```

### Ideal Profiles

```
1. E-commerce owner: "I want to increase profit margin from 10% to 15%"
2. Service business: "I want to reduce CAC from Rp200k to Rp100k"
3. SaaS founder: "I want to improve conversion from 2% to 5%"
4. F&B owner: "I want to find which product line to scale"
5. Agency: "I want to find new revenue streams"
```

## Pilot Flow

```
SELECT PARTNER
      ↓
UNDERSTAND BUSINESS (30 min interview)
      ↓
IMPORT BUSINESS CONTEXT (onboarding 5 steps)
      ↓
DEFINE BASELINE T0 (revenue, cost, CAC, conversion)
      ↓
CREATE REAL OBJECTIVE (specific economic target)
      ↓
AEE RUNS CYCLE 1 (KIMI research → opportunities → select)
      ↓
HUMAN REVIEW (approval mode — autonomy level 2)
      ↓
GLM EXECUTION (mission: real action)
      ↓
MEASURE REAL RESULT (evidence-based)
      ↓
KIMI INTERPRETS (what happened → what next)
      ↓
CYCLE 2 → CYCLE 3 (iterate based on learning)
      ↓
COMPARE T0 vs T1
      ↓
VERIFIED ECONOMIC OUTCOME
      ↓
PAYMENT TEST
```

## Autonomy Setting: Pilot 1

```
AUTONOMY LEVEL: 2 (APPROVAL REQUIRED)

KIMI proposes  →  Customer reviews  →  APPROVE  →  GLM executes

Do NOT use autonomy 3 (controlled) for first partner.
Wait until we have:
- Approval rate > 80%
- Execution success rate > 70%
- ≥ 3 completed cycles with evidence
- Zero irreversible damage
```

## KPIs (Non-Vanity)

### Product
```
Activation Rate:           % of signups that create first objective
Time To First Value:       hours from signup to first KIMI result
Objective Completion:      % of objectives reaching DECISION_READY
Mission Completion:        % of missions executed successfully
```

### AI
```
Agent Success Rate:        % of cycles completing without agent error
Schema Failure Rate:       % of model calls rejected by schema
Provider Failure Rate:     % of calls failing (timeout/5xx)
Mission Recovery Rate:     % of failed missions that retry successfully
```

### Economic
```
Revenue Impact:            Rp delta (T1 − T0)
Profit Impact:             Rp delta (T1 − T0)
Cost Saved:                Rp delta (T0 − T1)
CAC Improvement:           % reduction
Conversion Improvement:   % point increase
```

### Customer
```
Weekly Active Users:       partner engagement
Objectives Created:        count
Repeat Usage:              multiple objectives
Retention:                 still using after 30 days
Willingness To Pay:        YES/NO + amount
```

### Ultimate KPI
```
CUSTOMER SAYS:

"AUREX produced a measurable economic result
that I would not have achieved otherwise."
```

## Payment Test

After verified value created:

```
IF verified profit impact ≥ Rp10jt/month:
  → Ask: "Would you pay Rp2jt/month for AUREX?"
  → If YES: invoice Rp2jt for next month
  → If NO: ask what amount they would pay

IF verified profit impact ≥ Rp50jt/month:
  → Ask: "Would you pay Rp5jt/month for AUREX?"
  → If YES: invoice Rp5jt
  → If NO: negotiate

IF no verified value:
  → Do NOT ask for payment
  → Iterate or pivot
```
